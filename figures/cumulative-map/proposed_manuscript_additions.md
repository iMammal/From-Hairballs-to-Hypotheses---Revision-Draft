## Section 4 — analytical tasks

Across the expanded examples, task support depends less on display novelty than on how computed structure remains available for inspection. focusedMDS and distnet expose discrepancies between projected and high-dimensional distances, while PathwayMatrix reorganizes pathway relations through ordering, grouping, and lenses; both make comparison a check on representation rather than a terminal visual readout.~\cite{ExpandedE34,ExpandedE37} In time-varying embryo data, the Space-Time Hypercube links a spatial selection to descendants across time and coordinated representations, coupling precision interaction with temporal sensemaking.~\cite{ExpandedE22} These examples also delimit the evidence: worked cases demonstrate capability, while only the Space-Time Hypercube includes formative domain-expert sessions, whose mixed task findings caution against treating a supported operation as uniformly beneficial.

## Section 5 — assistance

The expanded reports sharpen the distinction between responsive computation and adjustable controls. In VR annotation, positive and negative clicks cause a learned model to revise the segmentation across a volume; this feedback-to-model loop supports Algorithmic and Adaptive placement.~\cite{ExpandedE24} In mixed-reality liver navigation, newly captured surface evidence triggers deformation correction of the preoperative model, so the intervention changes with the developing surgical context rather than with an entered parameter alone.~\cite{ExpandedE15} ASCRIBE-XR resolves underspecified choices among segmentation, resolution, meshing, and rendering operations from an open-ended request, providing an implemented Conversational workflow and a narrower Adaptive contribution, although no user study establishes its benefit.~\cite{ExpandedE28} By contrast, fixed threshold alerts in Rapid QC-MS and explicit feature weighting in aneurysm retrieval remain Algorithmic here: automatic execution or recalculation does not by itself show that the system inferred an analysis state and selected a different intervention.~\cite{ExpandedE48,ExpandedE46}

## Section 6 — modality

Cross-modality reports show why modality must be verified at the mechanism level. MinOmics supports the same redox-proteomics investigation by juxtaposing structures on a high-resolution wall and superposing them in a headset, whereas BioNet-XR implements network algorithms on desktop and in VR but explicitly limits its mixed-reality version to importing and navigating networks.~\cite{ExpandedE07,ExpandedE26} The latter also evaluated usability only on desktop: participants viewed videos of the immersive versions. Display availability therefore cannot be used as evidence that the same analytical assistance is implemented or evaluated across modalities. Similarly, the generic anatomical-model report states that its Java tools can run in a CAVE but provides no CAVE-specific execution evidence, so that potential combination remains uncounted.~\cite{ExpandedE01}

## Section 7 — evaluation

The expanded evidence reinforces the need to separate implementation, usability, and analytical benefit. A 192-task VR annotation study with three radiologists found higher annotation quality for two participants but not the third, alongside concern about unlocalized model changes.~\cite{ExpandedE24} Five biologists using the Space-Time Hypercube agreed on utility for wave detection yet reported mixed results for division and asynchrony tasks and difficulty forming efficient workflows.~\cite{ExpandedE22} BioNet-XR's 30-person study supports desktop usability only, while liver mixed-reality navigation reports phantom registration error rather than clinical decisions or outcomes.~\cite{ExpandedE26,ExpandedE15} These studies are stronger than implementation demonstrations, but their endpoints should not be collapsed into a common claim of scientific effectiveness.

## Section 8 — challenges and opportunities

Several reports expose failure modes that should shape future assistance. Projection in the Space-Time Hypercube can discard spatial information and create misleading apparent shrinkage when objects move away from the cutting plane; juxtaposing the source geometry is a partial safeguard.~\cite{ExpandedE22} PathwayMatrix's binary decomposition supports overview and discovery but weakens temporal order and causal tracing, while focusedMDS shows that low-dimensional proximity can obscure the original distance structure.~\cite{ExpandedE37,ExpandedE34} These are not arguments against computation. They motivate interfaces that preserve links to source evidence, disclose transformation assumptions, and make correction consequential. Adaptive and conversational systems add a related provenance burden: analysts need to see which contextual signals or language-derived choices changed the executed workflow.
